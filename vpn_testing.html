開咗 VPN 仲連唔到／出唔到街？按「情況 A（虛擬網卡甩線）」或「情況 B（舊 DNS 污染快取）」對症處理即可。
情況 A：VPN 顯示已連線但完全出唔到街虛擬網卡甩線 · 最常見
當實體網卡短暫斷線重連、切換網絡或剛改完網卡設定後，VPN 虛擬網卡（TUN / TAP）會死抱住舊網絡接口，導致流量送唔出街。
⚠️ 點解單靠 ipconfig /flushdns ＋ curl.exe 救唔到？
flushdns 只係清「域名翻譯簿（DNS 快取）」，curl.exe 只係「敲門測試」；兩者都唔會重新綁定虛擬網卡或重置 IP 路由表，所以必須先徹底重開 VPN 客戶端再刷新 IP。
1
徹底退出 VPN 客戶端：先喺 VPN 軟件按斷開連線，再喺 Windows 右下角系統托盤（時間旁邊向上箭嘴）搵到 VPN 圖示，右鍵揀 Exit / 退出，確保背景進程完全結束（唔好只按右上角 X 縮小）。
2
刷新本地網卡 IP 同 DNS 路由：按 Win + R 輸入 cmd 開命令提示字元，執行下面兩句：
CMD / POWERSHELL 
ipconfig /flushdns
ipconfig /renew
3
重開 VPN 並切換一次節點／模式：重新啟動 VPN 客戶端，先揀另一個可用節點（或切換一次「系統代理 System Proxy」／「TUN 虛擬網卡模式」），再按連線。
4
驗證外網通道恢復：執行 curl.exe -v https://api.ip.sb/geoip 見到出境外 IP JSON，再按下面掣重新檢測。
情況 B：通道暢通但仲食緊舊中國直連快取清 DNS · 需 Admin
適合「剛連上 VPN，但網頁仲顯示中國直連或連唔到境外站」嘅情況（需用 「以管理員身分執行」 嘅 PowerShell）：
1. ipconfig /flushdns：必須用 Admin（清除系統級 DNS 污染快取，普通權限會出 Request requires elevation）。
2. curl.exe -v https://api.ip.sb/geoip：唔需要 Admin，用來強制經 VPN 通道發送一次外部請求「預熱連線」。
1
最快開法：直接按鍵盤 Win + X，喺彈出選單揀 「終端機 (系統管理員)」 或 「Windows PowerShell (系統管理員)」（亦可喺搜尋欄打 PowerShell 右鍵揀以管理員身分執行）。
2
複製下面兩句指令貼入去按 Enter 執行：
POWERSHELL (ADMIN) 
ipconfig /flushdns
curl.exe -v https://api.ip.sb/geoip
💡 點樣知成功？如果 curl.exe 吐出一堆 JSON 數據（例如 {"ip":"...","country_code":"..."}），代表系統已經成功經 VPN 預熱連線；等 10 秒左右再按下面掣重新檢測就得啦。

其他平台清 DNS（Mac / iPhone / Android）

macOS（終端機 Terminal）：
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
輸入 Mac 登入密碼時畫面唔會顯示字元，直接打完按 Enter 即可。
iPhone / Android 手機：
先開 VPN，然後開啟手機 「飛航模式 (Airplane Mode)」等 5–10 秒再熄返，強制手機中斷並重建網絡介面與系統 DNS 快取。

瀏覽器層面急救（Chrome / Edge）

有時 Windows 清咗，但 Chrome / Edge 自己仲留住舊 DNS 同 Socket 連線池：
1
開無痕視窗測試：按 Ctrl + Shift + N（Mac：Cmd + Shift + N）開無痕模式再打開本頁，完全避開舊快取。
2
清瀏覽器 DNS 快取：複製下面網址貼去網址列，入面按 「Clear host cache」：
chrome://net-internals/#dns
3
清瀏覽器 Socket 連線池：再貼下面網址，入面按 「Flush socket pools」：
chrome://net-internals/#sockets
4
檢查代理模式與安全 DNS：確認 VPN 客戶端已開啟系統代理／TUN 模式（或試切「全局模式 Global」）；若瀏覽器設定開啟咗「使用安全 DNS (DoH)」，可暫時關閉以免查詢繞過 VPN。
點樣解讀：瀏覽器基於安全限制，只量到「有冇回應／幾快」，證明唔到「真正用到個網站」。出口 CN＝中國直連；出口非 CN＝VPN 通道生效。綠燈＝連線事實；出口喺中國時，被牆站就算有回應都多屬 DNS 污染／劫持／快取殘影。
